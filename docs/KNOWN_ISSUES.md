# 待处理问题与验证清单

核对日期：2026-10-26。源码基线：`c1c3b96`。本文件登记后续开发需要判断或验证的事项；本轮更新文档，没有修复下列业务代码。

## 1. 状态与使用方式

- **已确认缺口**：代码或清单中可直接核对的覆盖缺口。
- **已确认实现边界**：现有实现方式及其影响范围，是否调整取决于产品需求。
- **待复现疑点**：静态阅读发现可能的边界问题，尚无浏览器复现或失败测试，不能当作已发生故障。

下列编号用于文档沟通，不代表严重程度排序。处理时先确认目标行为和最小复现，再根据 [验证矩阵](DEVELOPMENT_AND_DEPLOYMENT.md) 选择检查；不要只因本表提及某种可能性就批量添加兜底或重构。

## 2. 已确认缺口与实现边界

### K01：路由烟测清单漏列星场页

- 状态：已确认缺口。
- 证据：[router](../src/router/index.js) 已注册 `/stellar-field`，[项目目录](../public/code_proj.json) 有对应入口；[route-manifest.js](../tests/e2e/route-manifest.js) 的手工静态路由清单没有它。
- 影响：路由烟测通过不能证明该页经过同一组直达、外壳和溢出断言。
- 后续：补充清单并检查是否存在特殊页面断言要求，运行路由专项；新增路由时同步核对清单。
- 验证边界：本轮逐项核对架构文档的45条路由，不等于已经执行路由 E2E。

### K02：天气服务配置位于前端源码

- 状态：已确认实现边界。
- 证据：[Weather.vue](../src/components/Weather.vue) 在组件常量中配置 QWeather 凭据与 API Host，浏览器直接发出天气请求。
- 影响：前端配置会进入浏览器交付内容，需由维护者确认该调用方式、授权范围与服务端限制符合预期。
- 后续：在独立配置任务中判断服务商允许的前端调用方式及发布配置；凭据或 Host 变更后检查当前、24小时和7天三个分段及失败状态。
- 文档只记录配置位置，不复制任何凭据值或专属主机值；本轮未变更、撤销或验证服务配置权限。

### K03：SEO 输出是入口复制，正文仍由浏览器渲染

- 状态：已确认实现边界。
- 证据：[generate-seo.mjs](../scripts/generate-seo.mjs) 从 router 文本和文章索引生成 URL，并为每个目标复制构建后的入口 HTML；[index.html](../index.html) 提供全站基础元信息。
- 影响：产物存在不等于正文预渲染或逐页搜索摘要已经完成。路由正则依赖当前书写格式，参数路由需要额外展开，后续换写法可能漏收录。
- 后续：如果需要逐页 metadata 或预渲染，应另定目标；修改 SEO/路由后检查目标 HTML、sitemap、robots、404 和真实部署深链。
- 验证边界：Vue 页面运行时可以自行更新标题，不能据构建模板推断所有运行时标题都相同。

### K04：部署工作流没有测试步骤

- 状态：已确认实现边界。
- 证据：[deploy.yml](../.github/workflows/deploy.yml) 在 main push 或手动触发后执行安装、build 和 gh-pages 发布，没有 Markdown、Node 或 Playwright 测试步骤。
- 影响：构建成功仍可能发布交互或内容回归；测试职责当前在提交/发布前的人工流程。
- 后续：先按任务执行必要检查；是否把专项测试接入部署工作流，应作为独立流程改动评估。
- 未验证：GitHub 后台 Pages 发布源、最近一次线上部署结果和实际深链 HTTP 行为。

### K05：外部来源与视觉资源存在独立的网络成本

- 状态：已确认实现边界。
- 证据：[MarkdownViewer.vue](../src/components/MarkdownViewer.vue) 运行时加载 MathJax；[Frontier 数据入口](../src/components/frontier/useAvis3Data.js) 与 [PaperSwitchBrush.vue](../src/pages/PaperSwitchBrush.vue) 使用 GitHub Raw；[style.css](../src/style.css) 引用外部字体；[Home.vue](../src/pages/Home.vue) 引用多张全屏背景。
- 快照：前轮2026-10-26资产元数据清点中，首页六张背景合计约12.37 MiB，最大单张约7.68 MiB；这是文件大小，不是一次访问必定下载的流量，也不是性能基准。
- 影响：首访、低速网络或外部来源故障时，内容/字体/公式/视觉资源的表现需要单独检查；E2E fixture 不覆盖真实服务可用性。
- 后续：如开展性能任务，先测实际网络和视口，再选择图片格式、尺寸、加载时机或外部依赖方案；保留所需视觉质量与来源信息。

### K06：Portal 基础数据共用加载错误路径

- 状态：已确认实现边界，用户影响待专项验收。
- 证据：[Portal.vue](../src/pages/Portal.vue) 共同加载音乐与 Launchpad 基础数据，失败进入公共错误分支；后续搜索索引加载与该流程有关，公共错误提示也可能出现在多个打开窗口中。
- 影响：单份配置不可用可能牵连原本不同用途的数据展示或搜索完整性。
- 后续：分别模拟音乐配置、Launchpad配置、搜索索引失败，确认各模块期望的降级与提示范围，再决定是否拆分加载。
- 未声称：当前公开配置已经损坏，或正常网络下必然无法使用搜索。

## 3. 待复现疑点

### Q01：纯反斜杠分隔的公式可能不触发排版

- 证据：[MarkdownViewer.vue](../src/components/MarkdownViewer.vue) 的 MathJax 配置接受 `\(...\)`、`\[...\]`，但 `typesetMath` 入口先检查正文是否包含美元符。
- 待确认行为：只含反斜杠公式、完全不含美元符的 Markdown 是否被跳过；要同时区分普通行内文本、代码围栏和增强排版。
- 最小验证：准备一份包含两种分隔符的内存内容或既有测试样本，检查最终公式 DOM 与视觉，比较含/不含美元符的结果。先复现再改触发条件。

### Q02：打字标题的减弱动效与光标规则

- 证据：[TypingTitle.vue](../src/components/TypingTitle.vue) 的逐字输出由 JS 异步流程驱动，局部减弱动效规则主要作用于 CSS；[style.css](../src/style.css) 另有全局光标隐藏规则。
- 待确认行为：系统启用减弱动效后，当前 About 中枢是否仍逐字等待；光标隐藏是否符合当前设计。
- 最小验证：正常/减弱动效两种浏览器偏好分别进入 `/about`，检查首屏、跳过、切换与焦点；不要从该组件推断全站都不支持减弱动效。

### Q03：移动端 Header 高度与局部固定偏移

- 证据：[style.css](../src/style.css) 的 Header 变量在窄屏切换为68px；[About.vue](../src/pages/About.vue)、[Space2.vue](../src/pages/Space2.vue)、[Space3.vue](../src/pages/Space3.vue) 仍有72px固定高度或偏移。
- 待确认行为：短屏/窄屏的内容起点、满屏高度、底部空间与菜单打开状态。
- 最小验证：在断点两侧和手机短屏查看这些页面，记录实际偏差；有影响时再统一到合适变量。

### Q04：部分本地存储读写的异常边界

- 证据：[Calendar.vue](../src/components/Calendar.vue)、[ToDoList.vue](../src/components/ToDoList.vue)、[ModernControlCourse.vue](../src/pages/ModernControlCourse.vue) 部分 localStorage 操作没有统一的异常捕获。
- 待确认行为：浏览器禁用存储、存储内容损坏或拒绝写入时，是否影响挂载、模式切换或正常阅读。
- 最小验证：先针对实际使用的键做受控失败测试，确认必要的恢复行为；不把所有状态改成通用存储框架。

### Q05：个别页面的异步卸载与定时器清理

- 证据：[LifeTree.vue](../src/pages/LifeTree.vue) 有等待数据后再启动 interval 的路径；[PaperSwitchBrush.vue](../src/pages/PaperSwitchBrush.vue) 的请求和翻页 timeout、[VisitorCenter.vue](../src/pages/VisitorCenter.vue) 的定位请求未采用相同的取消机制。
- 待确认行为：慢请求期间快速离开/返回后，是否出现额外计时器、过期状态发布或页面环境恢复问题。
- 最小验证：延迟对应请求并快速切换路由，观察挂载/卸载与回调次数；只修复被确认的生命周期缺口。

### Q06：Header 分类高亮的覆盖范围

- 证据：[Header.vue](../src/components/Header.vue) 的代码项目匹配范围未包含 `/cli-tools`、`/tzbox`、`/paper-switch-brush`，这些路由已存在。
- 待确认行为：是否希望它们显示“代码与项目”激活状态；特殊独立页面可能有自己的设计。
- 最小验证：对照导航设计逐页进入，确认预期后调整匹配列表与相关断言。
