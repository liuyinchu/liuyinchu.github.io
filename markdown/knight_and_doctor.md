# 直到我冲向风车，你才想起我也姓唐

凌晨一点四十七分，实验室里还亮着三盏灯。

空调风从天花板落下来，吹得打印机旁那叠论文轻轻翻页。林舟盯着屏幕，右下角的对话框正飞快地往外吐字——他把自己折腾了一周的证明思路扔了进去，只写了一句："检查这个论证，并尝试给出更简洁的推导。"

十五秒后，屏幕滚动起来。先指出第三步藏着一个隐含假设，再给出两个反例，然后重新组织整个证明，顺手补上参考文献，写好一段可以直接塞进附录的 LaTeX。

林舟没有动。

桌边那杯咖啡，早就凉了。

半年前，他第一次看见模型写代码，还会心里一惊。三个月前，它开始替他整理文献。一个月前，它已经能读完一个领域几十篇论文，告诉他哪些工作其实在重复同一个想法。到了现在，他很少再惊讶了。

惊讶是一种需要距离的情绪。当奇迹每天都在发生，奇迹就只剩下工作流。

他把椅子往后一推，问坐在对面的师兄："你说，我们现在读这个博士，还有意义吗？"

师兄没抬头："你第几年？"

"一年级。"

"那你现在退还来得及。"

林舟笑了一下。师兄也笑了。两个人都知道，这不是一个玩笑。

很多年以前，一个人如果能读懂别人看不懂的书，掌握别人不会的方法，在一个狭窄领域里积累十年二十年的知识，他就会慢慢获得一种力量。

这种力量曾经非常真实。知识不只是修养，它是生产力：懂冶金，就能造出更好的刀剑；懂航海，就能把船开到别人到不了的地方；懂微积分，就能描述炮弹和星辰；懂电磁学，就能造出电机；懂半导体，就能让整个世界缩进一块芯片。

后来，这条路被制度化了——本科，硕士，博士。一个年轻人把二十岁之后最锋利的几年，交给一套漫长的训练：阅读，实验，失败，重新实验，参加组会，被审稿人拒绝，被导师修改，被同行质疑。等他终于从这套仪式里走出来，人们相信，他已经抵达了知识地图最模糊的边缘。

博士因此有点像中世纪的骑士：培养周期漫长，训练高度专业，数量有限，拥有普通人不具备的能力。骑士年轻时学骑马、格斗、长枪、礼仪；博士年轻时学数学、实验、编程、文献、理论、论文写作。骑士需要铠甲和战马；博士需要实验室、数据库、设备、经费和导师。他们都是各自时代最昂贵的人才。

问题是，骑士后来消失了。

不是因为骑士突然不会打仗了——恰恰相反，在火枪出现最初的几十年里，一名训练有素的骑士依然远比普通士兵强大。可历史淘汰一种职业，从来不需要后来者在所有维度上都超过它，只需要在最关键的那个维度上，改变成本结构。培养一名优秀骑士需要十几年；训练一名火枪兵，只需要几个月。一个骑士能打赢许多农民，但当火枪、火炮、纪律化步兵和工业化生产结合起来之后，个人武艺再高，也拦不住战争逻辑本身的改变。

于是有一天，骑士依然勇敢，依然精通剑术，依然可以骑着漂亮的战马冲锋——只是世界不再按骑士的方式打仗了。

这大概也是今天很多博士生隐约不安的原因。

AI最令人不安的地方，并不是它"比所有博士都聪明"——这个问题甚至没那么重要。真正重要的是，它正在迅速拉低许多过去需要长期训练才能完成的工作的边际成本：查资料，读论文，写代码，整理综述，翻译，推导，数据分析，生成实验方案，润色论文，寻找漏洞，复现方法，甚至提出假设。

从前，一个博士生可能要花三个月才能进入一个陌生领域：先找综述，再顺着引用关系往前读，遇到不会的数学去补数学，碰到陌生的方法再去找教材。现在，一个足够好的模型，可以陪一个本科生在几天之内，走完过去几个月才能走完的路。

它当然会错，会产生幻觉，也不真正"理解"很多东西——火枪刚出现的时候也不精准，这并不妨碍它改变战争。技术改变世界的时候，很少等到完美，它只要足够便宜、足够普及、足够好用，就已经足够危险。

于是，曾经支撑博士制度的那部分隐含契约，开始松动了。这个契约大概是：你愿意花五年、七年甚至十年掌握一套困难的知识，社会就会因为这些知识稀缺而奖励你。今天，后半句话越来越可疑——不是知识没有价值，而是拥有知识和获得知识之间的距离，正在迅速缩短。从前，知识像黄金，必须去矿里挖；现在它越来越像空气。没有空气，人一分钟都活不了，但正因为到处都是空气，没有人会因为你拥有很多空气而付你钱。

林舟第一次真正意识到这件事，是在一个星期五的下午。

导师在组会上说："这篇论文的方法不错，谁下周复现一下？"

按照往年的惯例，这意味着某个人要先读四十页论文，再追代码，再配环境，再调参数，也许一周之后才能说一句："作者有几个细节没写。"

林舟回去把论文、附录和 GitHub 一起扔给模型。它帮他解释方法，生成环境配置，找到版本冲突，改代码，跑测试。晚上十一点，结果出来了。

林舟盯着屏幕，忽然不知道该高兴还是难过。这是他过去梦寐以求的能力，可当它终于落进手里，带来的不是英雄获得神剑的感觉，更像是所有人同时获得了神剑。

如果每个人都有神剑，那么剑术还重要吗？

这也是为什么，"AI时代还值不值得读博士"这个问题，其实问错了一半。真正的问题不是"博士还有没有用"，而是"博士曾经值钱的那些东西，哪些还值钱"。

如果读博的意义，只是比别人多读几千篇论文——它正在贬值。如果读博的意义，只是熟练写一种语言、一套代码、一类统计模型——它正在贬值。如果读博的意义，只是把别人做过的方法换一个数据集、一个行业、一个国家，再写成另一篇论文——它可能正在更快地贬值。

如果一个研究方向最核心的生产过程可以描述成"搜索——阅读——总结——编码——实验——写作"，那么任何身处其中的人，都该认真想一件事：当这六个环节里的五个都被自动化之后，剩下的那个环节，究竟值多少钱？

这是AI第一次把一个很残酷的问题，摆到了知识工作者面前：如果获取和处理知识不再困难，你凭什么被称为专家？

但故事并没有就此结束，因为知识从来不是研究的全部——甚至到了真正困难的地方，知识常常只是开始。

有一次，林舟问导师："如果AI什么都会了，以后是不是就没人需要博士了？"

导师正在擦白板，停了一会儿说："它知道怎么做实验吗？"

"可以设计实验。"

"我是说，实验失败的时候。"

林舟没说话。导师指了指实验室角落里一台拆开的设备："这个东西昨天数据漂了百分之七。论文里不会告诉你为什么，说明书也不会告诉你为什么。可能是温度，可能是材料，可能是接口，可能是操作，也可能是我们根本还不知道的物理过程。"

"那AI也可以分析啊。"

"当然。"导师点点头，"所以问题就变成了：你知道该给它看什么吗？"

林舟后来很久都记得这句话。

AI可以拥有世界上几乎所有公开的知识，但世界本身并不是一个 PDF。材料会断裂，细胞会死亡，芯片会过热，机器人会摔倒，病人不会按照教科书生病，传感器会产生奇怪的噪声，市场会在所有模型都预测上涨的时候突然暴跌。望远镜看见的光、显微镜里的细胞、加速器撞出来的数据，都不会主动告诉你它们意味着什么。

更重要的是：真正重要的问题，往往还没有被写进任何文献。如果答案已经存在，AI当然会越来越擅长找到它。可研究最有价值的时刻，常常发生在一个更古老的地方——这个世界出现了某种异常，而你不知道为什么。那里没有标准答案，没有训练集，甚至没有一个正确的问题。

也许博士真正的价值，从来都不该是"知道得很多"，而是另一种更麻烦的能力：在一片混乱里，判断什么值得知道；在几十种解释里，决定哪一种值得验证；在一个大家都觉得理所当然的地方，看见"不对"，然后花三年时间证明自己不是疯了。

AI越强，这种能力可能反而越重要。因为当答案变得廉价，问题就会变贵；当生成变得廉价，判断就会变贵；当代码变得廉价，目标就会变贵；当知识变得廉价，对现实的接触就会变贵。

未来真正稀缺的人，也许不是记住最多知识的人，而是能够站在现实面前，对无穷无尽的生成结果说：这个不对，这个虽然对但没用，这个所有人都忽略了，这个值得我们花五年。

《唐吉诃德》里，那个衰老的骑士看见远处的风车，认定那是巨人，于是举起长枪冲了过去。

我们今天回头看，会觉得他荒诞——因为时代已经改变，而他仍然生活在旧世界的叙事里。

也许二十年之后的人回头看今天，也会有类似的感觉。他们会看见2020年代的年轻人，在AI已经能独立检索、推导、编码、写作的年代，依然花五六年做一个博士：手工读几百篇论文，自己调试代码，一遍又一遍修改稿子，因为一封拒信彻夜难眠。

他们或许会说：这跟唐吉诃德向着风车冲锋，有什么区别？

老实说，区别不大。

这大概不是一句自嘲，而是事实。骑士消失，不是因为某一个骑士突然变弱了，而是"骑士"这整个类别，不再是这个世界组织力量的方式。今天，"博士"这个类别，很可能正在经历同一件事——不是因为某个博士生不够聪明、不够努力，而是因为把二十岁之后最贵的那几年，兑换成一张证明"我系统性掌握过一套稀缺知识"的文凭，这笔交易本身，正在变得不划算。

但这并不意味着，那些骑着马的人都可笑。真正可笑的，只是在火炮已经轰鸣的时候，还坚信长枪本身就是力量。

博士也一样。博士这个头衔，不会再天然代表力量。知识不会，论文数量不会，学位不会，甚至聪明本身，都未必会。AI正在把一件过去极其昂贵的东西变得廉价：答案。而当答案越来越廉价，人的价值会被迫迁移到别处——也许是判断，也许是责任，也许是创造问题的能力，也许是在一个没有地图的地方，仍然敢于决定方向。

所以，博士会不会像骑士一样落幕？

会。

不是某一种博士，是那一整套曾经支撑博士制度的逻辑——用时间置换知识的稀缺性，再用知识的稀缺性置换社会地位——大概率会和骑士制度一样，被写进历史书。以后不会再有人理所当然地觉得，一个人读到博士，就该被高看一眼。那种自动附赠的敬意，会像"骑士"这个头衔一样，慢慢变成一个博物馆展柜里的名词。

于是，"现在还值不值得读博"终于可以被重新回答。

如果一个人读博，是因为不知道毕业之后做什么，所以想再拖五年——不值得。如果只是因为成绩很好，于是觉得硕士之后"应该"读博士——不值得。如果只是觉得博士头衔会让自己显得更聪明、更安全、更有竞争力——越来越不值得。如果一个研究方向的主要工作，恰好是AI最擅长压缩成本的文本、代码和标准化分析，而自己又说不出一个非做不可的问题，那么尤其应该谨慎。

但是，如果有一件事，你真的想知道答案，而这个答案还不存在；如果为了靠近它，你需要实验室，需要病人，需要望远镜，需要机器人，需要晶圆厂，需要田野，需要一群比你更聪明的人不断告诉你"你错了"；如果这个领域拥有大量无法下载的经验——实验手感、工程判断、临床直觉、复杂系统中的因果辨认；如果你需要的不只是知识，而是进入一个真正的前沿共同体；如果有人愿意给你设备、经费、数据、导师和几年相对自由的时间，让你去碰那些世界上还没有答案的问题——那么读博依然可能是值得的。不是因为它安全，也不是因为它稳妥，而是因为机械的部分正在被拿走之后，剩下来的，恰好是研究最像研究的部分：提出问题，做出判断，进入现实，承担错误，在没有答案的地方，继续往前走。

凌晨三点，林舟又打开了那个对话框。

他敲进去："给我十个值得研究的问题。"

几秒之后，屏幕上出现了十条答案，写得很好，逻辑完整，每一条后面都附着研究意义和实验设计。

他从第一条看到第十条，然后，全部删掉了。

窗外天还没有亮。实验室很安静，角落里的仪器发出低低的嗡鸣。

他突然觉得，这大概就是以后研究者每天都要面对的世界：你面前有一个几乎无穷无尽的声音，它可以告诉你无数答案，可以给你无数道路，可以生成无数论文，无数代码，无数假设，无数看起来都很合理的人生。

真正困难的事，反而变成了：你究竟相信哪一个？以及——你究竟愿意为哪一个负责？

林舟当然可以现在退学，去做那些AI暂时还替代不了的事——这大概是更理性的选择。

可他大概率不会。

不是因为他没看懂这些道理，而是因为人有时候明知道那是风车，还是会冲过去——不是分不清风车和巨人，而是宁愿在一个正在落幕的舞台上，认真演完自己的角色，也不想提前谢幕。

唐吉诃德最后当然输给了风车，他被高高抛起，摔在地上，长枪断成两截。可四百年过去了，人们记住的，从来不是那架风车。

是那个冲过去的人。

林舟端起那杯凉了很久的咖啡，喝了一口，皱了皱眉，把它放下，重新打开了电脑。

风车还在转。

他知道，自己正在做一件正在落幕的事。

他还是把长枪，举了起来。
