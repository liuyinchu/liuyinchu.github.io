# AVIS3 Arena

> 评测版本 avis3-v1 · 发布版本 0.1.0-candidate.3\
> 最新完整正式验收：2026-10-09 · 成绩复核：2026-10-11（Asia/Shanghai）

## 项目与公开范围

AVIS3 在内部 HPC 平台私有部署。本页公开项目介绍、正式规则、获准发布的成绩与频谱快照。

这是一个面向 Agent 的长程控制规则开发任务：理解动力学模型，在开发环境中分析、实现和测试规则，再把规则交给独立的正式验收环境。语言模型参与规则的开发；仿真中逐步执行的是提交的规则程序。

成绩对应当前提交的模型与运行工具组合。仿真结果用于理解这些提交的表现，不构成通用 AI 产品排名，也不等同于实物验证。

## 控制任务与交互规则

对象包含 10 个内部状态，接口提供 3 路物理控制力输入和 3 路速度输出，另有 2 路私有扰动注入通道。系统存在通道耦合，三个输出不能直接理解为三个独立运动轴。

每个仿真步读取当前带噪观测，提交规则返回 3 路控制力；每路力限制在 ±0.5 N。对象推进一步后产生下一个输出。初始观测不计分，计分使用更新后的真实速度；测量噪声影响规则能看到什么，不直接叠加到评分真值上。

| 设置 | 本版本条件 |
| --- | --- |
| 内部状态 | 10 个 |
| 控制输入 / 速度输出 | 3 路 / 3 路 |
| 私有扰动注入 | 2 路 |
| 采样频率 | 10,000 Hz |
| 每轮仿真时长 | 1,000 秒 |
| 每轮仿真步数 | 10,000,000 |
| 正式验收轮数 | 10 个独立随机轮次 |
| 控制力限制 | 每路 ±0.5 N |
| 真实速度单位 | m/s |

提交的规则程序在仿真步上执行。10 kHz 是采样频率，不表示语言模型每秒推理一万次，也不保证程序按墙钟时间实时运行。

### 可以使用哪些信息

参测者可以分析和使用公开的连续、离散控制模型，以及维数、单位、采样率、时长、限幅和评分定义，也可以从自己的合法观测与动作中进行辨识或推断。

实际内部状态、扰动耦合部分、私有信号资料、随机种子、真实输出和未来观测不向规则开放。其他选手的数据与裁判私有资料也不属于开发输入。

## 提交规则与验收流程

规则可以采用 **Python、Rust/C ABI 或声明式离散矩阵**。提交的是一套能接入竞技场的控制规则，核心行为是根据带噪观测给出物理控制力；参测者也可以附上简短的开发心得。

### 接口与工作区操作

每轮创建新的规则实例。逻辑接口包括初始化 `reset(public_model, public_config, rule_config)`、逐步执行 `step(tick, noisy_observation)` 和结束释放；规则可以保存自己的内部状态与历史。

在维护者分配的工作区中，可用以下命令检查、测试和提交：

```sh
./arena check
./arena test
./arena test --no-wait
./arena status RUN_ID
./arena submit
```

`submit` 保存当前规则的快照，之后修改工作区文件不会改变已提交快照。心得可放在清单的 `report` 字段，最多 600 字符。上述命令针对已分配的内部工作区；本页展示公开资料。

### 一次完整验收

1. **开发与试验。** 在独立的开发环境中分析模型、实现规则并查看自己的测试结果。默认开发测试为 1 轮，单轮条件与正式验收一致。
2. **提交与预检。** 检查提交清单、规则入口与编译等接入条件。预检不通过时先修正提交，不补造十轮失败成绩。
3. **正式验收。** 对提交的规则执行 10 个独立随机轮次，每轮完成 1,000 秒仿真。开发与验收使用独立随机场景；各选手同编号轮次也不是同一个场景。
4. **发布最新结果。** 只有整组取得完整终态后，才更新均值、标准差、逐轮分数和对应的诊断结果。重测过程中继续保留上一份完整成绩。

新一组完整结果会替换旧结果，即使新均值更低，也保留最新完整结果，不保留历史最高分。基础设施中断或取消而未完成整组时，不发布新总分；评测条件改变时使用新版本，不把不同版本混排。

## 评分公式

令 $y_i[k]$ 表示更新后第 $i$ 路真实速度，$f_s=10{,}000$ Hz，$N=10{,}000{,}000$。速度响应函数为：

$$
\operatorname{sigmoid}(z)=\frac{1}{1+\exp(-z)}
$$

$$
c(v)=\operatorname{sigmoid}\!\left(
\operatorname{clip}\!\left[
-\frac{2\ln(19)}{10^{-4}}\left(|v|-5\times10^{-5}\right),
-60,60
\right]\right)
$$

单轮积分为：

$$
J=\frac{1}{f_s}\sum_{k=1}^{N}\prod_{i=1}^{3}c\!\left(y_i[k]\right)
$$

正式成绩是 10 轮原始积分的均值，越高越好。本版本理论上限为 **857.375**，条形图按这一量程展示。这个分数不是扰动消除百分比。

三个通道的响应值在每个采样点相乘，再累积整轮积分。因此，某一路的残余速度仍可能影响整体得分。评分没有单独加入动作幅值或动作变化惩罚；控制力限制仍由交互规则执行。

## 均值、标准差与失败轮次

对 $R=10$ 轮积分计算：

$$
\overline{J}=\frac{1}{R}\sum_{r=1}^{R}J_r,\qquad
s=\sqrt{\frac{1}{R-1}\sum_{r=1}^{R}(J_r-\overline{J})^2}
$$

标准差使用样本标准差（ddof = 1），描述这组独立随机轮次之间的波动，不是置信区间。

规则崩溃、非法输出或数值发散时，该轮记为 **-1**，继续执行其余轮次，失败分数照常参与十轮均值。有限速度超过 0.001 m/s 时会记录诊断，仿真仍继续整轮。基础设施中断或未完成整组验收时，不发布新的最终成绩，保留上一份完整结果。

## 位移等效频谱与读图方法

[查看本次 30 轮频谱](#spectra)。每位选手都有 10 轮，按选手与轮次选择后，可以查看三路输出的位移等效幅度谱密度（ASD）。频谱对应本页 2026-10-09 的完整验收组，图表资料于 2026-10-12 复核。

每轮把 **受控真实速度输出** 与 **相同初态、相同扰动的无控制基线** 对照。图中的基线属于当前这一轮，不把其他选手同编号轮次作为配对基线；用于开发的带噪观测也不作为这两条曲线的输入。

### 如何计算

先对真实速度序列使用 Welch 方法估计功率谱密度（PSD），再将速度 ASD 换算为位移等效 ASD：

$$
\operatorname{ASD}_{x}(f)
=\frac{\sqrt{\operatorname{PSD}_{v}(f)}}{2\pi f},
\qquad f>0
$$

| 频谱设置 | 本版本参数 |
| --- | --- |
| 方法 | Welch PSD |
| 采样率 | 10,000 Hz |
| 分段长度 / FFT 点数 | 1,000,000 / 1,000,000 |
| 窗函数 | 周期 Hann |
| 重叠点数 | 500,000（50%） |
| 去趋势 | constant |
| PSD 标定 / 平均 | density / mean |
| 频谱形式 | 单边谱 |
| 频率间隔 | 0.01 Hz |
| 展示范围 | 0.01–100 Hz，仅正频率 |
| 位移等效 ASD 单位 | m/√Hz |

这里的位移等效量由速度频谱除以 $2\pi f$ 得到，没有在零频处进行换算，也不是直接观测到的位移轨迹。

### 怎样解释曲线

- 横轴为频率，纵轴为位移等效 ASD；两轴采用对数刻度，用于观察不同频段与数量级。
- 同一通道、同一轮中，受控曲线低于无控制基线，表示这一频段的残余响应更小。局部峰值和不同通道之间的变化，也属于需要观察的控制表现。
- 先查看同一轮的受控／基线关系，再切换其他轮次观察表现是否稳定。不同选手的随机场景不相同，不能只按轮号做严格的成对比较。
- 曲线纵轴随所选轮次的实际数值调整，读图时同时查看刻度，不能仅凭线条在画面中的高低判断不同图的绝对差异。

::folding{title="为什么频谱表现与总分不一定完全一致？"}
ASD 描述响应在频率上的分布；正式成绩来自真实速度序列的逐点非线性响应和三通道乘积，再对整轮积分。因此，频谱是理解控制效果的诊断材料，不能直接替代积分总分，也不能从一个频段的改善推导整体排名。
::

## 比较边界

开发预算、人工帮助和完整开发过程没有统一审计。独立随机验收能够提供额外观察，但不能据此断言不存在过拟合。结果只说明当前提交在本版本评测条件下的表现。

本页公开的是经过核验的仿真结果快照，暂不提供公开参赛入口。解释成绩时，应同时考虑模型与运行工具、评测版本、规则提交、轮次波动和频谱诊断。
